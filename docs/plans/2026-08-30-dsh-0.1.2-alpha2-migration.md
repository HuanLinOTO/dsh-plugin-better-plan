# @huanlin/dsh-plugin-better-plan · dsh 0.1.2-alpha.1 → alpha.2 迁移指南

> 生成日期：2026-08-30 · 基于插件 v0.4.0 源码与上游 tag `dsh-v0.1.2-alpha.1` (cd5ef81481) → `dsh-v0.1.2-alpha.2` (0a53fb55be) 的只读 git 对象分析。
> 证据命令均为只读：`git -C D:/Projects/deepseek-harness/dsh show|diff|grep dsh-v0.1.2-alpha.2 -- <路径>`。

## 结论

**⚠️ 需适配（一处编译期硬断裂，改动极小）。** 上游在 folds→projections 迁移中把 `foldPlanMode` 从 `@deepseek-ai/dsh-plan-mode` 的公开导出中**移除**（`packages/plan/plan-mode/src/index.ts`，208 行 diff），而本插件 host 半部对其有**运行时具名 import**——不改动则 `dsh web` 加载本插件直接抛 `SyntaxError: ... does not provide an export named 'foldPlanMode'`，插件整体失效。其余 dsh 面（工具契约、session 事件、system-prompt assemble、webServer 路由、client sessions/locale/better-sidebar 交互、ui-primitives 组件）经逐项核对**全部兼容**，preset 的 `plan:policy` 四处锚点句原样保留，提示词改写逻辑无需动。修复 = 内联一个 10 行的本地 fold 函数 + 重建 `lib/`。

## 迁移步骤

> 前置（人类操作，遵循 dsh 升级 SOP）：先把 `~/.dsh/source/current` 升到 alpha.2（`git pull --ff-only` → `pnpm install --prefer-offline` → `pnpm run build`，前台长 timeout）——**不先升级源码树，本插件的 `pnpm run typecheck` 就会立即报 `foldPlanMode` 缺失**，这正好是预期中的早期信号。

### 1. 代码改动（唯一必须的适配：内联本地 fold）

上游把 plan-mode 状态折叠迁入 projection 注册表后，`foldPlanMode` 不再是公开 API；且 preset isolate realm 里注册的投影对本插件 ctx 不可达，故**不采用** `ctx.sessionProjections.stateOf(session,'plan')` 路线（realm 归属待人工确认），而是照 alpha.2 官方测试的做法内联本地 fold——语义与 alpha.1 完全一致（log 上最后一条 `plan/mode` 胜出）。

1. **新建 `src/plan-fold.ts`**：
   ```ts
   /**
    * Local fold of the logged plan-mode state (last `plan/mode` wins; a log
    * with none folds to inactive). Replaces the `foldPlanMode` export that
    * dsh 0.1.2-alpha.2 removed from @deepseek-ai/dsh-plan-mode when plan
    * state moved into the `plan` session projection.
    * @module @huanlin/dsh-plugin-better-plan/plan-fold
    */
   import type { SessionEvent } from '@deepseek-ai/dsh-session'

   export function isPlanModeActive(events: readonly SessionEvent[], end = events.length): boolean {
     let active = false
     let index = 0
     for (const event of events) {
       if (index >= end) break
       index++
       if (event.type === 'plan/mode') active = event.data.active
     }
     return active
   }
   ```
   （`'plan/mode'` 的事件类型增强仍由 plan-mode 的 types 提供——`@deepseek-ai/dsh-session/types` 子路径映射必须保留在 tsconfig.json L28。）

2. **`src/index.ts`**：L44 改为 `import { EXIT_PLAN_MODE } from '@deepseek-ai/dsh-plan-mode'`（`foldPlanMode` 从 import 中移除；本文件只用它做 plan-mode 常量之外的 fold），并新增 `import { isPlanModeActive } from './plan-fold.ts'`；L83 `if (!foldPlanMode(session.events))` → `if (!isPlanModeActive(session.events))`。

3. **`src/shadow-tool.ts`**：L38 同样改为只导 `EXIT_PLAN_MODE`；L193 `if (!foldPlanMode(agent.session.events))` → `if (!isPlanModeActive(agent.session.events))`。

4. **`tests/composition.spec.ts`**：L17 的 `import { foldPlanMode } from '@deepseek-ai/dsh-plan-mode'` 改为 `import { isPlanModeActive } from '../src/plan-fold.ts'`；全文 15 处 `foldPlanMode(...)` 调用改名（`rg -l foldPlanMode tests/` 核对清零）。
